# Task 09 — Royalty-free music assets

**Plan ref:** docs/plan.md §9
**Depends on:** none

## Objective
Commit a small curated set of genuinely royalty-free soundtracks for the render
step, with attribution tracked.

## Checklist
- [ ] Add ~3–5 CC0 / CC-BY tracks under `assets/music/` (Pixabay Music / Incompetech /
      Free Music Archive).
- [ ] Add `assets/music/CREDITS.md` listing each track, source, license, and required
      attribution string.
- [ ] Confirm filenames are stable identifiers Claude can choose from (`music: <filename>`).

## Done when
- `assets/music/` holds playable tracks and a complete `CREDITS.md`.
- Each track's attribution string is ready to store in `videos.music_attribution`.
